The TUI is an interactive app in your terminal. It's the easiest way to look around, check runs and make quick changes without remembering commands.

```bash
subscriber
```

Run it with no arguments, after [signing in](/quickstart#1-sign-in).

## Getting around

Choose a workspace, then an environment, then a section. Use the arrow keys and `Enter` to choose.

| Key | Anywhere |
| --- | --- |
| `Esc` | Go back. |
| `q` | Quit. |

The workspace list also has **My Account**, and the environment list has **Billing**.

Each environment has these sections: **Subscribers**, **Workflows**, **Broadcasts**, **Run History**, **Integrations** and **Analytics**.

## Keys

| Screen | Keys |
| --- | --- |
| Workspaces, environments | `n` new |
| Subscribers | `n` new, `/` search |
| A subscriber | `e` edit, `t` tags, `p` opt in or out, `d` delete |
| Workflows | `n` new |
| A workflow | `t` trigger, `r` runs, `e` edit, `g` triggers and exit conditions, `d` delete |
| A broadcast workflow | Also `b` send a broadcast, `h` past broadcasts |
| A broadcast | `p` pause, `r` resume, `c` cancel, `s` retry anyone it missed, `b` back |
| Runs, Run History | `Enter` show a run, `b` back to the list |
| Integrations | `n` connect one |
| An integration | `e` edit, `p` make primary, `d` remove |
| Billing | `u` upgrade, `p` manage billing; `a` switches monthly or yearly while choosing |
| My Account | `e` edit |

Each screen shows its keys at the bottom.
